This repository is a synthetic portfolio demonstration project created by **Daniel Rodriguez III** for educational and professional demonstration purposes.

- **Data Origin**: All datasets (`dim_campaigns.csv`, `fact_marketing_touchpoints.csv`, `fact_conversions.csv`, `marketing_attribution_kpis.csv`) are synthetically generated using Python (`Faker`, `NumPy`, `Pandas`) to simulate real-world digital marketing telemetry and real estate search journeys.
